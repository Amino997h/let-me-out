# Let Me Out (LTO) 🌍✈️

منصة متجاوبة بالكامل مع شاشات الهواتف وأجهزة سطح المكتب لعرض ونشر أحدث فرص السفر، الهجرة العشوائية، برامج المقاطعات، المنح الدراسية، عقود العمل، والتطوع الدولي.

## المميزات:
- **Mobile-First Design**: واجهة سريعة وخفيفة مصممة لسهولة التصفح بالأصابع على الهاتف مع شريط تنقل سفلي سريع.
- **لوحة تحكم للمدير (`/admin`)**: نموذج مبسط لإضافة وحذف الفرص وتحديد الدولة، علم الدولة، نوع التمويل، والشروط، ورابط التقديم الرسمي.
- **جاهز للاستضافة على InfinityFree**: مبرمج بـ PHP原生 و MySQL متوافق 100% مع خوادم InfinityFree.
- **تصنيفات وفلاتر فورية**: فرز سهل حسب نوع الفرصة (هجرة، عمل، منحة، تطوع) ومحرك بحث سريع.

## طريقة التثبيت على InfinityFree:
1. ارفع ملفات هذا المجلد إلى مجلد `htdocs` في الاستضافة.
2. ادخل إلى **phpMyAdmin** في حسابك على InfinityFree واختر قاعدة البيانات `if0_42610278_LTO`.
3. اضغط على **Import** وارفع ملف `schema.sql` لإنشاء الجداول والبيانات التجريبية.
4. لوحة الإدارة متوفرة على الرابط: `https://lto.free.je/admin`
   - اسم المستخدم: `admin`
   - كلمة المرور الافتراضية: `admin123`
